# SOMA-CELL 0.6-P0.0
## Chemical Body Contract Layer — 化学身体APIの凍結

更新日: 2026-08-01

SOMA-CELL 0.6-P0は、0.5の化学身体へ神経系をまだ追加せず、将来の物質神経組織が身体と接続するための**失敗閉鎖型インターフェース**を固定する準備版です。

この版の中心命題は次です。

> 神経組織は、身体を直接書き換える特権的なPythonオブジェクトではなく、実在する化学量を読み、身体から有限予算を受け、既存の物理エフェクタへ要求を出し、壊れたときには物質へ戻る組織でなければならない。

P0には、再帰神経、学習、報酬、因果監査、反証コンパイラはありません。これらはP1以降で一つずつ戻します。

---

# 1. 0.5を凍結した理由

SOMA-CELL 0.5には、次がすでにあります。

- 局所膜材料から生じる動的境界
- 内外非対称な物質輸送
- 可変長物質ゲノムと遺伝子発現
- 代謝損傷、修復、機能年齢
- 物質感覚運動と生涯可塑性
- 死体化学、環境DNA、水平遺伝
- 可動配列と宿主負担
- 分裂・死亡・漏出・DNAを含む物質台帳

神経統合の途中で0.5の軌道まで変えてしまうと、神経の効果と身体改変の効果を切り分けられません。

そこでP0は、基準ファイル `SOMA_CELL_0_5_pythonista.py` を変更せずに読み込み、神経ポートが未使用の場合には0.5と**状態・乱数を含めて完全に同じ軌道**を保つ設計です。

凍結0.5基準ソースのSHA-256:

```text
5f37ac140e5a5e5cbf0e2f48597e3366ea3710a112f35940de35aae1e1931459
```

# 2. 新しく追加した四つの契約

## 2.1 読み取り専用の物理センサー

`ChemicalBodyPort.raw_sensor_fluxes()` は、次のような実在の化学・膜状態を返します。

- 36膜区画の材料量、閉鎖度、酸化、損傷痕跡
- 膜上輸送体の局所量
- 外部粒子・受容体リガンドの膜区画別プロファイル
- 外部ストレス、死体信号、環境DNA信号、死体毒信号
- 直前の物質流入、表面フラックス、DNA流入、死体摂食量
- ATP、燃料、鉱物、廃棄物、反応性物質、凝集体、ゲノム損傷
- 速度、膜張力、漏出量

次は渡しません。

```text
reward
fitness
correct_action
food_direction
autopoietic_margin
絶対位置
世界年齢
細胞年齢
```

返される辞書は再帰的に読み取り専用で、配列はコピー後にwrite-protectされます。センサーを読むだけでは、状態も乱数生成器も変化しません。

## 2.2 保存的な神経予算

将来の神経組織は、身体から次の四つを要求できます。

| 予算 | 物質的意味 |
|---|---|
| ATP | 活動・組立・エフェクタ実行に使う化学エネルギー |
| protein | 燃料と鉱物から切り出したタンパク質基質 |
| membrane | 膜前駆体 |
| signal | 燃料・鉱物由来の有限シグナル前駆体 |

`allocate_budget()` は、要求量、時間当たり上限、身体側に残す最低予備量を同時に確認し、渡せる量だけをエスクローへ移します。

未使用予算は `return_unused_budget()` で元の身体プールへ逆変換できます。配分と返却は物質保存下で行われます。

基質を神経組織へ組み立てる `commit_material()` では、さらにATPを消費します。物質基質を確保しただけで、無料の神経組織が生まれることはありません。

## 2.3 物理エフェクタ要求

許可された要求は次の四つだけです。

```text
motor
transporter_polarity
repair_polarity
quiescence
```

神経側は「右へ移動した」という結果を直接書き込めません。例えば運動要求は、既存の0.4/0.5膜収縮機構へ有限の表面力を加えます。位置はその後の身体物理更新によってのみ変わります。

以下の直接書き換えは拒否されます。

```text
position / velocity
membrane / membrane_mass
ATP / pools
DNA / genome / sequence
cell_id
未知の命令
```

実行にはエフェクタタンパク質、ATP、有限シグナル分子が必要です。予算がなければ、無料の運動も輸送体再配置も発生しません。

## 2.4 壊れた神経組織の物質返却

`return_dead_tissue()` は神経組織を削除するのではなく、保持していた物質を次へ戻します。

- 機能／損傷タンパク質 → 身体の分解対象タンパク質
- 凝集体 → 凝集体プール
- 膜材 → 膜前駆体
- シグナル物質 → 廃棄物
- 毒性物質 → 反応性物質
- 残存ATP → 散逸エネルギー

宿主細胞が死ぬ場合は、神経物質を先に身体へ返した後、0.5の死体へ変換します。分裂前にも神経物質を回収し、娘へ無料の神経組織や記憶をコピーしません。

# 3. この版に神経はない

`NullNeuralTissue` は、契約の接続確認用で、何も読み、要求し、計算しません。

P0の `P0World.step()` は、神経コールバックを実行せず、凍結0.5の `step()` へ一度だけ委譲します。

したがって、P0で見える「neural」という名前は、将来の組織用の物質エスクローと監査記録です。知能や学習が生じたという意味ではありません。

## 4.2 工学比較

3 seed × 5条件、計15試行、各5秒です。

| 条件 | 0.5完全一致 | 有限値 | 平均エフェクタ回数 | 平均ATP支出 |
|---|---:|---:|---:|---:|
| 凍結0.5 | 3/3 | 3/3 | 0 | 0 |
| P0未接続 | 3/3 | 3/3 | 0 | 0 |
| Null接続 | 3/3 | 3/3 | 0 | 0 |
| 予算配分→全返却 | 3/3 | 3/3 | 0 | 0 |
| 有料エフェクタ負荷 | 0/3 | 3/3 | 180 | 0.164327 |

有料エフェクタ条件が0.5と一致しないのは正常です。実在ATPと信号物質を消費し、身体へ物理作用を与えたためです。

この比較は、APIが物理的に機能することの確認であり、神経や知能の利益を示すものではありません。

# 6. P0の合格判定

P0の目的は、神経の性能向上ではなく、0.5身体との境界を固定することです。

今回、次を満たしました。

1. 未接続時に凍結0.5と完全一致する  
2. センサーが読み取り専用で、意味済み正解を渡さない  
3. 予算が身体の実在量と予備量を超えない  
4. 物理エフェクタ以外の直接書換えを拒否する  
5. 組織の生成・活動・返却に物質とATPの台帳がある  
6. 死亡・分裂で無料の神経物質・記憶を作らない  
7. 保存復元とロガーが決定論を壊さない  

したがって、P0は**P1のための凍結化学身体APIとして合格**と判定します。

# 7. 次の段階 — SOMA-CELL 0.6-P1

P1では、初めて物質神経細胞を1個だけ接続します。

その神経細胞は最低限、次を持ちます。

- ゲノム由来の区画・チャネル・受容体タンパク質
- 有限シグナル分子
- ATP依存の活動
- 入力フラックスの局所予測
- 運動／輸送体再配置要求
- 損傷、分解、再合成

主対照は、同じ量の物質と同じ維持費を持つが、情報処理しないダミー組織です。

P1の成功条件は「神経が発火した」ではありません。

```text
神経による身体利益
− 神経のATP・材料・損傷費
> 同費用ダミー組織
```

が少なくとも一つの非定常環境で成立する必要があります。

# 8. 限界

- P0に神経・学習・因果監査はない
- Pythonista Sceneの正確な表示、FPS、発熱はiPhone実機未確認
- 工学比較は短時間・3 seedで、性能統計ではない
- 0.5の化学文法と物質種類は設計者定義
- 生命、意識、オープンエンド進化を証明していない

P0は「賢い生命」ではなく、**今後の神経を身体から特権化しないための厳格な接続規格**です。
