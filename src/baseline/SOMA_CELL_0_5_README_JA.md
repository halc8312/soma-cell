# SOMA-CELL 0.5
## 死体化学・環境DNA・水平遺伝・共有化学生態系

Build: `SOMA-CELL 0.5.0`  
対象: Pythonista 3 / iPhone、またはCPython + NumPy

---

## 1. この版の目的

SOMA-CELL 0.4では、物質ゲノムから受容体と原始運動器が発生し、細胞は環境勾配へ応じてATPを使って移動できるようになりました。

しかし、死んだ細胞はまだ生態系上の「情報源」ではありませんでした。死後の物質を匿名粒子へ即時変換すると、次の二つが失われます。

1. どの物質が一つの個体として組織化されていたか
2. その個体が持っていた物質ゲノムがどこへ移動したか

0.5では、死を削除処理ではなく、次の変換として扱います。

```text
生細胞
  ↓ 構造的崩壊
空間上に残る死体
  ├─ 膜・タンパク質・代謝物・毒性物質
  └─ 完全または途中の物質ゲノム
        ↓ 分解・放出
環境粒子 + 環境DNA
        ↓
別細胞による摂食・分解・拒絶・組込み
```

狙いは「死に意味がある」と宣言することではありません。検証する問いはもっと狭いものです。

> 死後も物質と遺伝情報を保存したまま環境へ移し、その一部が別個体の自己生産機能へ因果的に参加できるか。

## 2. 0.4から追加した主要機構

### 2.1 空間的な死体

死亡細胞は、すぐ匿名粒子になりません。死体は位置、半径、由来系統、死因、経過時間を持ち、物質を五つの区画で保持します。

| 死体区画 | 内容 |
|---|---|
| labile | 燃料・代替基質・中間体 |
| mineral | 鉱物・遊離ゲノムモノマー |
| protein | 正常/損傷タンパク質・凝集体 |
| structural | 膜・輸送体・隔壁材料 |
| toxic | 廃棄物・反応性物質 |

完全ゲノム、複製済みゲノム、複製途中鎖も、死体内の明示的なポリマーとして残ります。

死体化した直後の非ATP物質量は、生前の細胞物質量と一致します。ATPは化学自由エネルギーとして散逸側へ記録されます。

### 2.2 死体の段階的分解

死体は一度に消えません。

- 可溶性物質は比較的速く流出
- タンパク質は加水分解されて燃料・鉱物・廃棄物へ変換
- 膜や輸送体はより遅く崩壊
- 毒性物質は周囲へ放出
- 構造崩壊が進むほどゲノムが露出

分解された物質は、既存の粒子場へ戻ります。環境DNAを無効化した条件でもゲノム質量は消えず、鉱物性モノマーへ戻ります。

### 2.3 環境DNA（eDNA）

死体から放出されたゲノムは、位置を持つDNA断片になります。

各断片は次を保持します。

- 実際の記号列
- 位置
- 由来細胞・由来系統
- 元ゲノムのハッシュ
- 損傷量
- 可動配列かどうか
- 経過時間

断片は拡散し、両端から侵食され、最終的には鉱物性モノマーへ戻ります。DNA断片数の上限を超えた場合も、情報は失われますが物質は保存的に環境へ戻されます。

### 2.4 遺伝子から作られる環境DNA装置

0.5の創始ゲノムは480記号、30遺伝子です。0.4の化学・感覚運動遺伝子に加えて、次の7機能をコードします。

| 機能 | 役割 |
|---|---|
| competence | DNAを膜近傍から取り込む |
| recombinase | 外来断片を完全ゲノムへ組み込む |
| nuclease | 組み込まないDNAをモノマーへ分解 |
| restriction | 外来性の高い配列の組込み確率を下げる |
| necrophage | 死体物質を取り込む |
| detox | 死体由来の反応性物質を減らす |
| vesicle | 可動配列の外部放出を助ける |

可動配列遺伝子は創始ゲノムにはありません。比較試験では、外部から物質として入った場合にだけ利用できます。

### 2.5 ATPを払うDNA取り込み

DNAが近くにあるだけではゲノムへ入りません。

```text
近接したDNA断片
  + competenceタンパク質
  + ATP
  ↓
細胞内へ取り込み
```

取り込んだ後は、次のいずれかになります。

- 組換えに成功し、断片記号が完全ゲノムへ挿入
- 制限系によって拒絶
- ATP不足で組込み不能
- ヌクレアーゼで分解し、ゲノムモノマーとして回収
- 分解機能を無効化した場合は環境へ再放出

Python側で `recipient.genome = donor.genome.copy()` を実行する仕組みではありません。環境プールから実物の断片オブジェクトが取り除かれ、その記号と質量が受容細胞へ移動します。

### 2.6 物理的な水平遺伝

組込み時には、外来断片の長さ分だけ受容ゲノムが伸びます。ゲノム長上限はiPhone上の暴走防止のため640記号です。

外来断片が上限を超える場合、入らなかった分はゲノムモノマーへ戻ります。組込みには断片長と外来性に応じたATP費があります。

組み込まれた遺伝子は、通常の翻訳反応を経なければ機能しません。燃料、鉱物、ATP、翻訳触媒を消費してタンパク質を作り、その後で初めて反応網へ参加します。

### 2.7 死体利用（necrophagy）

近接した死体から、可溶性物質、タンパク質、鉱物、構造材を取り込めます。

取り込みにはATPが必要です。死体が毒性物質を含む場合は、一部が反応性物質として同時に入ります。detoxタンパク質が多いほど毒性共取り込みが減ります。

したがって死体利用は常に利益ではありません。

```text
得られる材料
－ 処理ATP
－ 毒性共取り込み
－ 修復費
```

が正味利益を決めます。

### 2.8 限定的な可動配列

可動配列遺伝子を得た細胞は、自分の遺伝子断片を環境DNAとして放出できます。

放出には、

- 可動配列タンパク質
- 小胞形成タンパク質
- ゲノムモノマー
- ATP

が必要です。

放出された配列は別細胞へ組み込まれ得ます。創始集団には存在しないため、比較試験では物質的な外来接種を一度行います。

可動配列は宿主に利益を与えるよう設計していません。実験では、広がる一方でATP費とゲノム肥大を生み、平均自己生産余裕を下げました。

## 3. 物質台帳

世界の物質総量には、次をすべて含めます。

```text
環境粒子
+ 生細胞の非ATP物質
+ 死体物質
+ 死体内ゲノム
+ 環境DNA
```

台帳の期待値は、

```text
初期総物質
+ 明示的な外部投入
- 明示的な散逸物質
```

です。

DNAの取り込み、組込み、分解、死体摂食、死体分解、可動配列放出では、物質を一方の区画から別の区画へ移すだけです。

42試行における最終物質残差の最大絶対値は、

```text
5.665759e-06
```

でした。これは数値積分と粒子削除閾値を含む粗視化モデルの誤差範囲です。

## 4. 20項目の決定論的検証

`SOMA_CELL_0_5_validation.py` は20/20 PASSです。

主な検査:

1. 創始ゲノムが7種類の生態装置を持ち、可動配列を持たない
2. 死亡時に生細胞物質と同量の空間死体が生じる
3. 即時匿名再利用アブレーションでは死体/eDNAが残らない
4. 死体分解が環境粒子とDNAへ物質を移す
5. DNA侵食後の全記号が鉱物物質へ戻る
6. DNA取り込みにcompetenceとATPが必要
7. 組換え無効時はDNAがモノマーへ分解される
8. 実断片の組込みが物質保存下でゲノムを伸ばす
9. 移入遺伝子が通常翻訳で機能タンパク質になる
10. 移入遺伝子が物理ゲノム複製と分裂を越えて遺伝する
11. 制限系が外来配列の実組込み頻度を下げる
12. 死体摂食が材料を移し、ATPを消費する
13. detoxが同量摂食時の毒性流入を減らす
14. 可動配列放出がモノマー・ATPを消費する
15. 放出断片が別ゲノムへ入る
16. donor→corpse→eDNA→recipient の全経路
17. eDNA無効化時にゲノム物質だけは回収される
18. 全生態装置費を払いながらG1分裂
19. 死体・eDNAを含む保存復元後の完全一致
20. ロガーが乱数や状態へ干渉しない

全機構の単一細胞はseed 101で約347.6シミュレーション秒後に物質保存型G1分裂へ到達しました。

## 5. 42試行の比較実験

3乱数系列×14条件を実行しました。各条件3試行なので、統計的証明ではなく機構比較です。

### 5.1 死体資源試験

資源を少なくした環境で、一匹を死亡させ、残った細胞を45秒観測しました。

| 条件 | 平均自己生産余裕 | 死体摂食量 | 毒性流入 | 平均損傷 |
|---|---:|---:|---:|---:|
| clean_full | **0.584632** | 2.570290 | 0.043060 | 0.015682 |
| clean_no_nutrition | 0.550742 | 0 | 0 | 0.008920 |
| clean_immediate_recycle | 0.443474 | 0 | 0 | 0.026418 |
| toxic_full | **0.553275** | 2.100413 | 0.079108 | 0.024595 |
| toxic_no_detox | 0.549929 | 2.404532 | **0.151083** | **0.031327** |
| toxic_no_nutrition | 0.454759 | 0 | 0 | 0.019528 |

清浄な死体では、死体摂食ありの平均余裕が摂食なしより高くなりました。即時匿名再利用は、この45秒条件では最も低い平均余裕でした。

毒性死体でも摂食機構は平均余裕を高めましたが、detoxを除くと毒性流入は約1.91倍になり、平均損傷も増えました。

重要なのは、死体摂食が無料のボーナスではないことです。最終時点の余裕や損傷順位はseedによって変わり、長い時間窓や別の毒濃度で利益が逆転する可能性があります。

### 5.2 制御された死体HGT試験

受容細胞から一つの反応遺伝子を除き、死亡ドナーの物質ゲノムへ同遺伝子を6コピー入れました。25秒の試験です。

| 条件 | 経路獲得成功 | 平均組込み | 平均分解 | 最終ゲノム長 |
|---|---:|---:|---:|---:|
| hgt_full | **3/3** | 4.667 | 1.333 | 538.67 |
| hgt_no_edna | 0/3 | 0 | 0 | 464.00 |
| hgt_no_recombination | 0/3 | 0 | **6.000** | 464.00 |
| hgt_no_competence | 0/3 | 0 | 0 | 464.00 |
| hgt_no_restriction | **3/3** | 4.333 | 1.667 | 533.33 |

全機構では、初期に欠けていた反応経路を3/3で獲得しました。平均初回獲得時刻は約0.593秒でした。

ただし、この試験は自然集団ではありません。ドナーが目的遺伝子を6コピー持ち、受容体のすぐ隣で死ぬ制御アッセイです。示したのは、物理的な経路が作動することです。自然環境で稀な有用遺伝子が安定定着する確率を示したものではありません。

HGTなし条件の平均自己生産余裕が全機構よりわずかに高い場合もありました。短期には、DNA取り込み・組換え・余分な遺伝子発現の費用が先に表れるためです。

### 5.3 可動配列試験

一匹へ可動配列を物質的に接種し、近傍に二匹の受容細胞を置きました。45秒の試験です。

| 条件 | 平均放出数 | 最終保有細胞 | 拡散成功 | 平均余裕 | 平均ゲノム長 |
|---|---:|---:|---:|---:|---:|
| mobile_export_on | 43.667 | **3.0** | 3/3 | 0.513016 | 593.78 |
| mobile_export_off | 0 | 1.0 | 0/3 | **0.631971** | 485.33 |
| mobile_no_restriction | **58.000** | **3.0** | 3/3 | 0.466639 | **620.44** |

可動配列は全試行で二匹の受容細胞へ広がりました。一方で、放出を止めた条件より平均自己生産余裕が低く、ゲノムが大きくなりました。

制限系を外すと、放出数・組込み数・ゲノム長がさらに増え、平均余裕はさらに低下しました。

これは重要な負の結果です。

> 情報が広がることと、宿主や生態系に役立つことは同じではない。

現行の可動配列は、限定された寄生的情報サイクルとして振る舞います。

## 7. 既知の限界

### 7.1 組換え文法は固定

ゲノムは可変長で、外来遺伝子を受け取れます。しかし、

- 物質種類
- 遺伝子解読規則
- 反応役割
- 組換え確率式
- ゲノム長上限

は人間が定義しています。

### 7.2 HGTは自然定着をまだ示していない

制御試験では有用遺伝子が移りましたが、多世代空間集団で稀な遺伝子が自然発生・伝播・固定したとは言えません。

### 7.3 可動配列は単純

可動配列は一種類の16記号遺伝子です。宿主特異性、複雑な感染段階、宿主防御との共進化はありません。

### 7.4 死体微生物相はない

死体分解は固定速度式です。分解者集団、発酵、酸素状態、微生物遷移はありません。

### 7.5 多細胞・文化・神経はまだ戻していない

0.5は0.6で既存SOMA神経系を戻す前の化学身体です。SOMA-5Rの内的世界、6Rの文化、7Rの多個体生態系を直接貼り付けてはいません。

### 7.6 生命・意識の証明ではない

0.5は、自己生産、物質遺伝、損傷修復、感覚運動、死後の物質・情報循環を持つ粗視化人工化学モデルです。生命の普遍的定義を満たしたと断定せず、意識や主観も主張しません。

## 8. 0.6へ渡すもの

0.6では、既存SOMAの局所神経・因果監査をこの物質身体へ戻します。

0.5から凍結する条件は次です。

1. 神経組織も死後にタンパク質・膜・情報物質として死体へ入る
2. 神経学習状態をPythonオブジェクトとして無料継承しない
3. 神経活動、予測、可塑性、監査、反証実験にATPと材料費を課す
4. 外来遺伝子や可動配列が神経発生遺伝子へ影響し得る
5. 死体・環境DNA・HGTを物質台帳から外さない
6. 神経系を除去しても0.5化学細胞として存続可能にする

最初から48細胞脳を戻しません。

```text
0.5化学身体
  ↓
ゲノム由来8〜12神経細胞
  ↓
局所予測・三因子可塑性
  ↓
神経コストを含むツイン比較
  ↓
因果監査・反証ゲート
```

という順序で統合します。

## 9. 現時点の正確な位置づけ

SOMA-CELL 0.5は、

> 死亡個体を空間的な物質・毒性・遺伝情報の貯蔵体として残し、その物質を別細胞が処理し、環境DNAをATP依存で取り込み、限定的な水平遺伝と寄生配列拡散を起こせる粗視化自己生産プロトセル生態系

です。

最も大事な成果は、機能数が増えたことではありません。

> **死んだ個体の物質と情報が消えず、別の自己生産循環へ入るまでを一つの保存台帳で追跡できるようになったこと**

です。
