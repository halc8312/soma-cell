# SOMA-CELL 0.6-P2.0
## Eight-Cell Material Recurrent Tissue — 8細胞の物質再帰神経組織

更新日: 2026-08-02  
身体ポート契約: `0.6-P0.2`  
親組織契約: `0.6-P1.1`  
P2組織契約: `0.6-P2.2`

SOMA-CELL 0.6-P2は、SOMA-CELL 0.5の自己生産化学身体へ、**8個のゲノム由来物質神経区画**を戻した段階です。

P1の1区画が等物質ダミーより小さなmoving-patch環境で有利だったことを受け、P2では旧SOMA-1の中心原理である、疎な再帰、局所予測、適格度トレース、三因子可塑性、成熟・再可塑化、構造再編を、P0の物質身体ポート上で小型化して再実装しました。

ただし、P2の結論は「大きい脳ほど賢い」ではありません。

> 規則反転後の同一状態ツインでは、可塑的8区画組織が等物質固定8区画をholdout 6 seed中5 seedで上回った。一方、局所予測と再帰の追加利益は確立せず、予測は一部比較でむしろ不利だった。

という、正負を含む限定的な結果です。

# 1. P0・P1から守った物質公理

P2の神経組織は、P0の`ChemicalBodyPort`以外から身体へ触れません。

できないこと:

```text
位置を直接変更する
ATP・燃料・膜・DNAを直接変更する
reward、fitness、正解方向を読む
autopoietic_marginを完成済み報酬として読む
学習済み配列を娘へ無料コピーする
神経細胞や結線を物質なしで生成・削除する
```

できること:

1. 膜区画の実分子分布、流入、ATP、損傷、膜状態を読む
2. ATP、タンパク質、膜材、有限信号分子を身体へ要求する
3. P0が許可した範囲で膜収縮と輸送体偏在を要求する
4. 壊れた神経物質を身体・死体プールへ保存的に返す

P2カセットを入れない条件では、P1と3 seed × 240 stepで状態とRNGが完全一致しました。

# 2. 8個の区画は物質ゲノムから発生する

創始細胞へ16記号の神経発生遺伝子を8本追加します。合計128記号です。

各遺伝子は、粗視化した次の形質を指定します。

- 膜上の方向選好
- 神経状態の時定数
- 可塑性速度
- 運動利得
- 発現量と複製忠実度

追加ゲノム、次回複製用モノマー、初期発生タンパク質は物質台帳へ含まれます。検証での明示的創始物質追加は`0.24192`でした。

各区画の標準物質目標は次です。

| 成分 | 1区画 | 8区画合計 |
|---|---:|---:|
| 機能タンパク質 | 0.0075 | 0.0600 |
| 区画膜 | 0.0025 | 0.0200 |
| 有限信号物質 | 0.0025 | 0.0200 |

P1区画を単純に8倍するのではなく、総組織量はP1の約1.6倍程度へ抑えています。全機構と固定8区画対照は、発生・物質目標・維持・摩耗スケジュールを共有します。

標準条件では、8区画すべてが約19 stepで成熟下限へ達しました。

# 3. 何を感じるか

各区画は12個の局所特徴を受け取ります。

- 外部分子4種の膜上分布
- x・y方向の濃度非対称
- 平均濃度
- 直前の膜流入
- ATP不足
- 反応性物質
- 膜閉鎖低下
- 内部物質保持低下
- タンパク質損傷・凝集

実粒子を右側へ置くと組織方向は右、左側へ置くと左へ反転しました。

```text
右側配置: dx = +0.0091
左側配置: dx = -0.0626
```

値が小さいのは、8区画の競合と物理エフェクタ上限を含むためです。符号が物理配置に応じて反転することを検査しています。

# 4. 20本の有限信号再帰接続

8区画を20本の有向接続でつなぎます。

再帰信号には、

- 有限信号分子
- ATP
- 正常チャネルタンパク質
- 活動に伴う摩耗

が必要です。

再帰なし条件では再帰メッセージが0になり、対応する費用も発生しません。

弱い接続は420 stepごとに候補評価され、同じ接続本数を保ったまま別接続へ生え替わります。変更には摩耗費があります。接続をNumPy上で消して無料の別接続を生やす方式にはしていません。

# 5. 細胞別の局所予測

各区画は、自分の次入力駆動を6個の局所特徴から予測します。

```text
現在の局所特徴
↓
次の自分の入力駆動を予測
↓
次stepの局所誤差で、その区画だけ更新
```

全ネットワークを貫く誤差逆伝播は使いません。

決定論的検証では、予測RMSが、

```text
0.015574 → 0.006452
```

へ下がりました。

ただし、身体利益については後述のとおり未確立です。**予測できることと、予測が生存費を回収することは別です。**

# 6. 適格度トレースと三因子可塑性

各区画へ小さな滑らかな内部摂動を加え、局所的に、

- 何を感じたか
- どの再帰信号を受けたか
- どちらへ動かそうとしたか

を適格度として約6.5秒の時定数で保持します。

第三因子は外部報酬ではなく、実身体から計算する4つの物理負債の変化です。

| 物理負債 | 実在する根拠 |
|---|---|
| エネルギー様 | ATP不足、利用可能燃料 |
| 境界様 | 膜閉鎖、漏出、保持率 |
| 損傷様 | 損傷タンパク質、凝集体、反応性物質 |
| 反応維持様 | 触媒機能、プロテオスタシス、廃棄能力 |

単体検証では、同じ適格度へ正負の身体結果を与えると、同じ重みが反対方向へ変化しました。

```text
基準     0.090000
改善後   0.090194
悪化後   0.089806
```

# 7. 分子エピソード記憶と急性害の記憶

通常の短い適格度だけでは、現在取り込んでいる資源分子が自分自身へ信用を付ける問題が起こりました。

そこで、外部分子の濃度が立ち上がった瞬間から約8秒のエピソードを作ります。

```text
分子の立ち上がり
↓
開始時の身体負債を記録
↓
8秒間、最大急性悪化と終端状態を観測
↓
終端改善 - 1.25 × 最大急性悪化
↓
その分子と運動の局所結合を更新
```

終わりに回復しても途中で大きく身体を傷つけた経験を、単純な成功として扱わないためです。

制御検証では、良い結果で`+0.026050`、悪化文脈で`-0.085000`となりました。

# 8. 発達費を外界の害と誤認しない

8区画の発生には大きなATP・材料費があります。開発中、その発達費を「そのとき存在した分子が悪かった」と誤認し、有用な初期結合を早期に壊す問題が見つかりました。

最終P2では、組織活動開始後34シミュレーション秒を発達安定期間としました。

- 局所予測は学べる
- 身体基準線を形成できる
- ただし感覚運動・再帰の長期可塑性は閉じる

反転時刻や正解を教える仕組みではありません。組織形成に伴う内因性費用が落ち着くまで、長期記憶を書き換えない臨界期です。

# 9. 規則反転環境

P2の主要評価では、現在の細胞位置を基準に、方向性手掛かり分子と、その数秒後の資源パッチを実粒子として放出します。

前半:

```text
手掛かりの方向 = 後続資源の方向
```

後半:

```text
手掛かりの方向と資源方向を反転
＋
手掛かり分子が膜を通過すると一部が反応性物質へ変換
```

普通の拡散だけでは、手掛かりと後続資源の空間分離が数秒で消えました。このままでは再帰・記憶を評価できないため、比較環境に全条件共通の物理的マイクロ流体トラップを置き、粒子を発生源付近へ緩く戻します。

これは開発seed `101/202/303`で、トラップ強度、手掛かり時間、運動スケールを調整したため、同じ3 seedの結果は校正内結果として分離します。holdout `404/505/606/707/808/909`は、その調整には使用していません。

# 10. 共通外乱ツイン

規則反転時点の完全状態を複製し、

```text

CONTROL  : 固定8区画 / 可塑性なし / 予測なし / 再帰なし
```

へ分岐させます。

各stepの乱数は、

```text
seed + step + subsystem + stream
```

から再構成します。片側だけが学習や再編で余分な乱数を消費しても、以後の無関係な外乱がずれません。

同じmode同士を120 taped step動かす検証では完全一致しました。

# 13. 各機構の正味価値

## 可塑性

開発seedの同一状態ツインで、全機構対可塑性なしは、

```text
平均AUC差 +1.056054
正のペア  2/3
```

でした。可塑性には小さいながら正の因果信号があります。ただし、holdoutで可塑性単独アブレーションを行っていないため、確立済みとまでは言いません。

## 局所予測

全機構対予測なしは、

```text
平均AUC差 -0.174359
正のペア  1/3
```

でした。予測誤差は下がりますが、現在の使用法が身体費を回収する証拠はありません。**予測は正式0.6でも必須アブレーションとして残し、縮小または棄却候補です。**

## 再帰

全機構対再帰なしは、

```text
平均AUC差 +0.016963
正のペア  2/3
```

でした。平均効果は極めて小さく、必要性は未確立です。遅延が短い現在課題では、再帰の追加費が利益と釣り合っていない可能性があります。
