SOMA-CELL 0.6.4 — START HERE
================================

1. ZIP内の全ファイルを同じPythonistaフォルダへ置く。
2. SOMA_CELL_0_6_4_pythonista.py を実行する。
3. 左上に SOMA-CELL 0.6.4 と出ることを確認する。

操作
----
膜をタップ      : 局所穿孔
空所をタップ    : 資源雲を投入
画面上部タップ  : 一時停止／再開
ダブルタップ    : 0.6.4ワールドへ安全にリセット

表示
----
option : 早期に物質として予約した完全準備比率
full   : 現在の完全準備比率
auth   : 証拠により完全準備を承認した個体数
ready  : 物理的に器官へ移せる準備がある個体数

重要
----
正式実験の科学判定は NEGATIVE_BOUNDARY_RESULT です。
95%未満の早期予約では登録3系列のどれも2区画器官を作れず、
95%予約を行った条件付き器官も未調整holdoutで全対照に敗れました。
これは神経一般の無価値を意味しません。
