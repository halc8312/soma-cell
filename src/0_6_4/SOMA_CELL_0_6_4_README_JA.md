# SOMA-CELL 0.6.4
## 費用償却境界と早期準備オプション

状態: **engineering PASS / scientific NEGATIVE_BOUNDARY_RESULT**

## 目的

0.6.3では、需要が見えてから一時神経器官を作る方式が短期課題で安定した純利益を出さなかった。0.6.4は、その原因の一つである「需要が分かる頃には身体材料が使い切られている」問題を測る。

神経器官を後から作る権利として、完全前駆体量の一部を早期に物質予約する。これは金融的な比喩ではなく、実際に身体から隔離されるタンパク質・膜・信号物質である。

## 新機構

- 低費用マイクロセンチネル
- 早期前駆体オプション
- 証拠に基づく完全準備の承認
- 周期的な物理規則変化
- 拡張分だけを返す保存的解除
- `option_no_tissue`費用整合対照
- bare、eager、常設2区画、ランダム発生との比較

## 物理的境界

登録3系列で40秒動かした結果:

| 早期オプション率 | 器官発生 |
|---:|---:|
| 0.25 | 0/3 |
| 0.50 | 0/3 |
| 0.75 | 0/3 |
| 0.85 | 0/3 |
| 0.90 | 0/3 |
| **0.95** | **3/3** |
| 1.00 | 3/3 |

つまり、今回の身体化学では2区画器官を後から作るために、ほぼ全量の材料を早期に予約する必要があった。条件付き投資で節約できる余地は5%程度しか残らなかった。

## 安全性

安定した移動パッチ環境12系列では、完全準備の誤承認も器官の誤発生も0件だった。判定ゲートは安定時に暴走しなかった。

## 未調整holdout

60秒の周期変化課題、6系列で比較した。

| 対照 | 条件付き − 対照 平均身体余裕AUC | 正ペア |
|---|---:|---:|
| 0.95 option/no tissue | -0.918171 | 1/6 |
| bare no tissue | -2.394640 | 0/6 |
| eager full preparation | -1.136416 | 1/6 |
| always efficient2 | -1.794204 | 2/6 |
| cost-matched random | -1.280801 | 1/6 |

事前登録の4/6正ペア条件を一つも満たさなかった。

## 正式な解釈

成立したもの:

- 早期オプションを実物質として保持できる
- 証拠後に完全準備へ拡張できる
- 低需要時に拡張分だけ返せる
- スケジュールを個体へ教えず周期変化を作れる
- 0.95という物理的実行境界を測定できた
- 安定環境で誤発生を抑えられた

成立しなかったもの:

- 早期予約費を大きく節約する条件付き器官
- bare、option-paid、eager、常設、ランダムの全対照を上回る領域
- 神経器官による総費用回収
