# SOMA-CELL 0.6.1
## 証拠充足と物質的な故障時神経保全

更新日: 2026-08-03  
状態: **凍結版 / engineering PASS, scientific PASS_WITH_LIMITS**  
実装スキーマ: `0.6.1-D1.4`  
正式リリース契約: `0.6.1-R2.0`

---

## 1. この版の目的

SOMA-CELL 0.6.0では、8区画の物質神経組織が自分の身体因果をABBA/BAAB停止監査し、
予測を校正し、反証後に期限付き資源リースを変更できるところまで統合した。

しかし、自然な短期意味反転では監査と校正は動いても、十分に高品質な反証から
自動feedbackへ進めなかった。

0.6.1では、次の二点を扱う。

1. `変化なし`と`証拠不足`を区別する。
2. 身体の運動変換機構が壊れた場合、壊れた器官へ無駄な命令を出し続ける神経区画を、
   有料の反復校正後にだけ一時休眠させる。

---

## 2. 0.6の物質公理を維持する

0.6.1でも次を変更しない。

- 境界は局所膜材料から生じる。
- 内部／外部輸送は膜と輸送体に依存する。
- ゲノム複製にはモノマー、ATP、複製触媒が必要である。
- 死はhealth値ではなく、境界と自己生産循環の回復不能な崩壊である。
- 神経活動、診断、監査、記憶、休眠にはATP・膜・タンパク質・有限信号物質が必要である。
- 神経は位置、ATP、膜量、DNAを直接書き換えない。
- 学習済み重み、因果証拠、遺伝子を無料コピーしない。
- 神経組織が死ねば、物質として身体／死体／環境DNA経路へ戻る。
- 外部reward、教師ラベル、正解方向を最上位目的へ渡さない。

## 3. 証拠充足度台帳

分子と身体チャネルごとに、次を記録する。

- 通常時の効果分布
- 最近の効果分布
- 観測証拠量
- 介入証拠量
- 身体文脈の範囲
- 最後に観測した時刻
- 変化後の証拠量
- 変化仮説の強さ

内部状態は少なくとも次へ分ける。

```text
insufficient_evidence
まだ判断できない

supported_stable
現在の規則を支持する実経験がある

suspected_change
結果が変化した可能性がある

confirmed_change
観察と介入が変化を支持する
```

接触しなかった時間を「効果ゼロ」として記録しない。実際に分子が膜を通過した経験だけを
意味証拠へ使う。

---

## 4. 低危険な能動診断

証拠が不足し、身体安全予算がある場合、細胞は短時間だけ次を行える。

- 分子勾配への弱い接近
- 輸送体の局所偏在
- 対象感覚経路の一時遮断
- 1〜2神経区画の可逆停止

診断はP0身体ポート経由で実行され、ATPと材料を支払う。位置を直接変更しない。

ただし、R2正式判定で強く支持されたのは後述する運動機構診断である。外部分子の能動的な
意味診断は、費用回収がまだ安定していないため実験機構として残す。

---

## 5. 神経ATPエスクローの会計修正

開発中、神経修復時に要求した固定ATPの未使用分が区画内へ過剰に残る問題が見つかった。
故障時リースがそのATPを身体へ戻すため、知的な節約効果を過大評価していた。

0.6.1では、再利用可能なATPを次へ制限する。

```text
神経1区画: 約0.002
8区画合計: 約0.016
監査コントローラー: 約0.004
```

タンパク質・膜の組立ATPは、今回実際に組み立てる材料量に比例して別途支払う。
未使用のATPと信号物質は身体へ保存的に返す。

この会計修正後にも故障時節約効果が残るかを、R2試験で改めて測定した。

---

## 6. 有料の運動機構校正

神経命令が実際の推進力へ変換される利得を記録する。

```text
神経運動要求
↓
P0身体ポート
↓
膜収縮エフェクター
↓
実際の推進力
```

通常時の基準利得を形成した後、利得低下が疑われた場合だけ短い校正パルスを実行する。

校正パルスは、

- ATP
- 有限信号物質
- コントローラータンパク質摩耗

を支払う。複数回の有料測定で利得低下が再現されるまで、故障を確定しない。

---

## 7. 期限付きの神経保全リース

故障が確認されると、運動へ強く寄与する2区画を短時間だけ休眠させる。

### 何を抑えるか

- 感覚入力の利得
- 入出力する再帰信号
- 内部活動
- 運動影響
- ATP・信号物質の利用上限

### 何を壊さないか

- 感覚重み
- 再帰重み
- 運動重み
- 恒常性パラメータ
- 神経物質総量
- ゲノム

学習済みパラメータは、そのステップの計算後に正確に復元する。活動低下、支出低下、
身体へ戻った余剰物質だけが実結果として残る。

故障が回復した場合、または期限が切れた場合、リースは撤回される。

---

## 8. 対象区画を「正の仕事」で選ぶ

旧開発版は、絶対運動強度の大きい区画を休眠対象へしていた。しかし、現在の運動へ逆向きに
働く拮抗区画を休ませると、かえって総運動命令が強くなる可能性がある。

0.6.1では、各区画の局所運動ベクトルを、組織自身の現在運動方向へ射影する。

```text
正の射影: 現在の運動へ寄与
負の射影: 現在の運動へ拮抗
```

正の仕事が大きい区画を優先する。外部の資源位置、最適行動、正解方向は使わない。

## 9. R1失敗とR2事前登録

### R1失敗

最初の事前登録では、故障校正の安全条件を生のエネルギー負債へ置いたため、P2身体の通常値と
尺度が合わず、故障12系列すべてで校正パルスが開始しなかった。

```text
安定誤リース: 0/20
故障適用: 12/12
故障確認: 0/12
リース: 0/12
```

この失敗は削除せず、失敗記録として保存した。

### R2前の開発

- 生エネルギー単独ではなく、構造損傷と処理停止を組み合わせた危機判定へ変更。
- 神経ATPエスクロー会計を修正。
- 運動へ正に寄与する区画だけを対象化。
- 開発seed 6系列で身体余裕AUCが6/6正。
- 安定開発seed 3系列で誤リース0。

その後、ソースSHA-256と未使用seedを事前登録して凍結した。

## 10. R2事前登録試験

### 主要試験: 身体中心マイクロ流体浴

既存粒子の量や種類を変えず、位置だけを各双子の身体中心へ再配置する。

- 燃料・鉱物: 身体周囲へ等方的に配置
- 中性ALT分子: 一方向へ配置し、神経運動要求を維持
- 廃棄物: 反対側へ配置

これにより、空間採餌の成功失敗と、壊れた運動器へATPを使う代謝費を分離する。
これは制御正対照であり、自然空間の普遍性能試験ではない。

### 未使用seed

```text
安定: 12001-12020
故障: 13001-13012
自然空間・探索的: 14001-14006
```

### 事前登録結果

| 指標 | 結果 |
|---|---:|
| 安定環境の誤リース | **0 / 20** |
| 安定環境の誤feedback | **0 / 20** |
| 故障確認 | **12 / 12** |
| リース発行 | **12 / 12** |
| 身体余裕AUC正 | **12 / 12** |
| 平均身体余裕AUC差 | **+0.0294916** |
| 平均運動ATP差 | **−0.000803644** |
| 平均散逸エネルギー差 | **−0.000774693** |
| 最大物質残差 | **3.126×10⁻⁶** |

主要な事前登録基準はすべて通過した。

等方的な栄養浴なので、短期物質取得差は0である。この試験の目的は、取得量を増やすことではなく、
同じ物質利用可能性の下で、故障した運動命令の費用を減らせるかを測ることだった。
