# SOMAプロジェクト継続ハンドオフ

作成日: 2026-08-01  
対象: SOMA-CELL 0.5完了地点〜0.6での既存SOMA神経系再統合

## 1. ユーザーの中心目的

iPhoneのPythonista上で、固定データセットや教師ラベルを前提にせず、身体・代謝・環境との相互作用の中で学び続ける人工生命を作る。単なるニューラルネットワークの高性能化ではなく、局所可塑性、自己維持、因果監査、形態形成、内的実験、文化、進化、物質的自己生産、物質遺伝、死後の物質・情報循環までを段階的に構成する。

新奇性を狙うが、奇抜さを優先せず、既知研究との差を明示し、アブレーションと反証可能な評価を必ず伴わせる。生命・意識・学術的新規性を検証前に断定しない。

## 2. 実行環境と制約

- 主対象: Pythonista 3 / iPhone
- 基本依存: Python標準ライブラリ、NumPy、Pythonista `scene`
- 長時間・多数系列の評価はCPythonでも実施し、Pythonistaでは表示と短縮試験を行う
- Scene実機表示、発熱、FPS、iOSメモリはiPhone側で最終確認する
- すべての版にビルド名を画面表示し、旧版混同を防ぐ
- 保存・復元、有限値、物質／エネルギー台帳、アブレーションを版ごとに検査する

## 3. 系譜の要約

### SOMA-0
単体人工生命。再帰神経系、身体代謝、三因子可塑性、次感覚予測、恒常性、構造可塑性。

### SOMA-1
48細胞の因果栄養組織。エネルギー・温度・完全性・疲労を単一報酬へ混ぜず、細胞別資源として扱う。細胞摂動から身体寄与を推定し、成熟・交代・資源交換へ接続。

### SOMA-2 / 2.1
細胞主張の実停止監査、器官仮説、可逆ON/OFF試験、期限付き器官リース。2.1でABBA/BAAB監査、イベント汚染分離、証拠失効、採択器官の撤去再審査を追加。

### SOMA-3
身体危険と情報価値を考慮した内生的問い生成。複数仮説を保持し、可逆な介入を選択。

### SOMA-4 / 4.1 / 4.2
因果説明を最大3命令の身体実験へ変換する反証コンパイラ。4.1で共通乱数ツイン実験室。4.2で変化監視、因果予測校正、変化時だけ開く期限付き再可塑化ゲート。

### SOMA-5R / 6R / 7R
旧5〜7を品質再構築した系統。
- 5R: 状態依存の短期内的ロールアウト、概念、思考コスト、休息時再生
- 6R: 同一物理世界、距離制限付き文化仮説、自己経験による信頼校正、限定継承
- 7R: 有限空間資源、出生・死亡・遺伝予算・系譜・生態系

SOMA-7R 1.0.1の実機長時間ログで、資源量0から再生不能になる数式上の罠が判明。1.0.2で休眠種子バンク、低資源時採取低下、資源安全度による出生抑制、飢餓時通信抑制を追加。Vaultでは1.0.2を基準とする。

### SOMA-CELL 0.1
動的膜、内部／外部の非対称輸送、触媒置換、廃棄、局所修復、物質保存型分裂を持つ自己生産核。固定health/integrity値ではなく、膜と反応循環の崩壊で死を定義。

### SOMA-CELL 0.2
可変長物質ゲノム、遺伝子発現、内部複製酵素、複製誤差、娘への完全ゲノム分配、タンパク質組成継承。初期にない反応辺が高速選択アッセイで生じ、選択で増え、ノックアウトで利益が消えることを確認。空間物理の多数世代進化とは区別する。

### SOMA-CELL 0.3
損傷タンパク質、凝集体、反応性副産物、膜酸化、ゲノム損傷を物質化。抗酸化、シャペロン、プロテアーゼ、ゲノム修復、損傷分配、校正、休眠、膜修復を遺伝子機能へ接続。固定寿命は置かず、修復・増殖・精度の配分から機能年齢を生じさせる。16/16検証PASS。

### SOMA-CELL 0.4
ゲノムから膜受容体、局所制御、収縮エフェクタ、輸送体極性を発生。膜36区画の実粒子・流入・張力・内部化学を読み、感知・運動・可塑性にATP費を課す。固定善悪表を使わず、自己生産余裕の変化へ局所可塑性を接続。18/18検証PASS。反転環境で自己生産余裕の小さな利益は得たが、有害化物質の一貫した忌避と意味符号反転は未証明。

### SOMA-CELL 0.5
死亡細胞を匿名削除せず、位置・由来・物質区画・完全／部分ゲノムを持つ死体へ変換。死体は段階分解し、粒子と環境DNAへ戻る。competence、recombinase、nuclease、restriction、necrophage、detox、vesicleを創始ゲノムから発生させ、DNA取り込み・組込み・分解・死体摂食・毒処理・可動配列放出にATPと物質費を課す。

環境DNAは実記号列、位置、由来、損傷、可動性を持ち、拡散・侵食・分解で鉱物へ戻る。HGTはPythonオブジェクトの無料コピーではなく、環境中の断片を取り除いて受容ゲノムへ挿入する物質移動である。移入遺伝子は通常翻訳を経て機能し、ゲノム複製と物質分裂を越えて娘へ遺伝する。

20/20決定論的検証PASS。3 seed × 14条件＝42試行。清浄死体の利用は45秒条件で自己生産余裕を改善。毒性死体ではdetox除去により毒流入が約1.91倍、損傷も増加。制御HGTでは全機構3/3で欠損経路を獲得し、eDNA・competence・recombination除去では0/3。可動配列は3/3で集団へ広がったが、宿主余裕を0.631971から0.513016へ下げ、ゲノムを肥大化させた。restriction除去ではさらに広がりと負担が増えた。最大最終物質残差は5.665759e-06。

## 5. SOMA-CELL 0.5までの検証済み範囲

- 物質ゲノムと複製途中鎖を台帳へ含める
- 内部複製酵素・モノマー・ATPがないと遺伝可能コピーを作れない
- 置換・挿入・欠失・重複・逆位・転位
- 物質損傷、費用付き修復、校正、損傷偏在
- ゲノム由来受容体、ATP支払い運動、輸送体極性、生涯可塑性
- 空間死体、段階分解、毒／栄養の交換関係
- 環境DNAの物質保存型拡散・侵食・回収
- competenceとATPを必要とする取り込み
- recombinationによる実配列組込み、nucleaseによる材料回収
- restrictionによる外来配列抑制
- donor→corpse→eDNA→recipientの機能遺伝経路
- HGT遺伝子の通常翻訳、物理ゲノム複製、娘への継承
- 有料の可動配列放出と、宿主負担を伴う感染拡大
- 死体・eDNAを含む保存復元後の決定論的一致
- 完全生態装置費を払いながらG1へ分裂
- 20/20検証、42比較試行、有限値、物質台帳

ただし、HGTドナーは欠損遺伝子を6コピー持つ制御条件であり、可動配列ドナーは一度だけ物質接種される。自然な多世代共有生態系での新経路発生・水平拡大・定着は未証明。

## 6. 重要な設計原則

1. 外部から正解ラベルを与えない。
2. 新機能は身体・化学コストを払う。
3. 遺伝可能物質をPythonオブジェクトの無料コピーで生成しない。
4. 物質・エネルギー・出生・死体・eDNA台帳の残差を記録する。
5. 単一報酬へ早期圧縮せず、維持変数の交換関係を残す。
6. 主張、予測、器官、学習、遺伝機構は介入試験とアブレーションで検証する。
7. 「生命」「意識」「新規性」を性能表示だけから宣言しない。
8. 旧版の成功説明より、実測ログと失敗原因を優先する。
9. 死亡は情報・物質の消去ではなく、物質プール間の変換として扱う。
10. 水平遺伝と可動配列には宿主費用・拒絶・分解の可能性を残す。
