# SOMA-CELL 0.6.3 正式契約 — 需要連動型一時ニューロジェネシス

## 目的

0.6.2で追加神経組織の短期費用回収が失敗した結果を親とし、常設神経ではなく、有料センチネルが物理的需要を検出したときだけ一時器官を発生し、費用込み価値監査で非正なら保存的に再吸収する。

## 凍結公理

1. 境界、代謝、遺伝、死体、eDNA、身体ポートは0.6.2までの物質公理を保持する。
2. センチネル、前駆体、器官、監査、再吸収はATP・膜・タンパク質・有限信号物質を消費する。
3. 外部報酬、正解方向、変化時刻通知、直接位置・ATP・膜・DNA書換えを使わない。
4. 器官発達中は神経計算を開始しない。
5. ACTIVE/DORMANT比較中は予測と可塑性の学習を凍結する。
6. 非正器官は物質を消さず、身体ポートへ返す。
7. 学習済み器官状態、プローブ状態、センチネル証拠を娘へ無料コピーしない。
8. 費用整合ランダム発生は世界RNGを消費しないカウンタ乱数を使う。

## 主要対照

- `prepared_no_tissue`: センチネル・前駆体費を持つが器官なし。主要な費用整合対照。
- `always_no_tissue`: 準備費も持たない裸の無組織対照。
- `random_cost_matched`: 状態非依存だが準備・発生費を払うランダム対照。
- `always_efficient2`: 常設2区画対照。

## 事前登録合格条件

- demand−preparedの平均身体余裕AUC差が正。
- 6 holdout中4以上で正。
- stable 12系列の誤発生が0〜1以下。
- 全試行が有限で物質残差が2e-5未満。

## 実測判定

- stable誤発生: 0/12 — 安全条件はPASS。
- demand−prepared平均AUC: +0.272332だが正は1/6 — 再現性条件FAIL。
- demand−bare no-tissue平均AUC: -0.621635、正1/6。
- demand−prepared物質取得: 平均+0.064033、正3/6。

したがって正式科学状態は`NEGATIVE_RESULT_WITH_LIMITS`とする。

## 許される主張

物質的な需要連動発生、期限付き器官監査、保存的再吸収を実装し、安定環境での誤発生を抑えた。しかし短い意味反転課題では、その戦略が準備・発生・維持・再吸収費を一貫して回収することは示されなかった。

## 禁止する過大主張

- 需要連動神経が一般に有利。
- 一時器官が常設脳より優れる。
- 神経が生命に不要。
- 自然な長期進化やオープンエンド進化が成立した。
- 生命・意識・主観を証明した。
