# SOMA-CELL 0.6-P1.0
## One Gene-Built Material Neuron — 物質ゲノムから発生する1神経区画

更新日: 2026-08-01  
身体ポート契約: SOMA-CELL 0.6-P0.2  
P1組織契約: 0.6-P1.1

SOMA-CELL 0.6-P1は、SOMA-CELL 0.5の自己生産化学身体と、旧SOMA-1〜4.2で育てた神経原理を再統合する最初の実働段階です。

ただし、いきなり48細胞脳を戻してはいません。P1にあるのは、**ゲノムから発生し、実物質とATPを使い、壊れれば物質へ戻る1個の神経区画**だけです。

中心的な問いは単純です。

> 同じ量の膜・タンパク質・シグナル物質を持ち、同じ維持費と同じ強さの行動要求を出すダミー組織より、環境化学を読む1神経区画は費用込みで身体を助けられるか。

結果は、今回の小さなmoving-patch環境では **3/3 seedで肯定的**でした。一方、局所予測器そのものの追加利益は一貫せず、まだ成功とは判定していません。

---

# 1. P0から守ったもの

P1はP0の`ChemicalBodyPort`を変更せず使用します。

神経区画は次をできません。

```text
位置を直接変更する
ATPや燃料を直接増減する
膜材料を直接書き換える
ゲノムを直接変更する
food_directionやrewardを読む
身体オブジェクトを参照する
```

できるのは次だけです。

1. P0が返す読み取り専用の分子流・膜・内部化学を読む
2. ATP・タンパク質基質・膜前駆体・有限シグナル物質を要求する
3. 受け取った材料をATP有料で組織へ組み立てる
4. `motor`と`transporter_polarity`を物理要求として出す
5. 壊れた区画を身体の損傷物質・凝集体・膜前駆体へ戻す

P1カセットを入れず、神経区画を接続しない条件では、P0と3 seed × 240 stepで状態と乱数軌道が完全一致しました。

---

# 2. 神経区画はゲノム由来

創始細胞へ、既存SOMA-CELL 0.4遺伝文法の予約済み領域を使う16記号の発生カセットを追加します。

カセットは無料のメタデータではありません。

- ゲノム鎖の16記号分の物質
- 次の完全コピーに必要な16記号分の遊離モノマー
- 創始時の最小発生タンパク質

を初期物質台帳へ加えています。

検証での追加創始物質は、

```text
0.03824
```

でした。

カセットを除くと、120 step後も神経区画は一度も発生しません。

娘細胞がカセットを持つには、通常のゲノム複製と物質保存型分裂が必要です。分裂時には既存神経区画を一度分解し、娘へ次を無料コピーしません。

- 活性状態
- 内部位相
- 予測重み
- 予測誤差
- 運動方向履歴

娘は受け取ったゲノムと身体物質から、区画を改めて発生させます。

# 3. 神経区画の実物質

標準区画は次の物質目標を持ちます。

| 成分 | 目標量 | 役割 |
|---|---:|---|
| 機能タンパク質 | 0.032 | 受容・積分・局所予測・発火の基盤 |
| 区画膜 | 0.010 | 化学身体内の局所区画 |
| シグナル物質 | 0.010 | 有限な活動・エフェクター要求媒体 |

形成中は身体へ材料とATPを要求します。成熟後も、活動用ATP、有限シグナル、摩耗置換用タンパク質を要求し続けます。

神経タンパク質は活動中に、

```text
機能タンパク質
→ 損傷タンパク質
→ 凝集体
```

へ変化します。

損傷量または凝集体量が閾値を超えると区画全体を保存的に分解し、ゲノムと化学身体から再発生させます。

開発中の検査で、機能低下によって成熟条件を外れた組織が損傷判定を回避する問題を発見しました。最終版では、成熟判定より先に物理損傷閾値を確認するよう修正しています。

# 4. 何を感じるか

標準カセットは燃料リガンドを選択します。ただし神経へ渡るのは「燃料方向」という答えではありません。

36膜区画で測った実リガンド分布から、局所的に次を構成します。

- x方向の濃度非対称
- y方向の濃度非対称
- 平均局所濃度
- 直前の膜流入量
- ATP不足
- 反応性物質
- 膜閉鎖低下
- 内部保持率低下

右側へ実燃料粒子を置いた検証では神経方向のx成分が`+0.9962`、左側へ置くと`-0.9962`になりました。

同じ身体ポートからは、次を受け取りません。

```text
reward
fitness
correct_action
food_direction
autopoietic_margin
absolute_position
world_age
cell_age
```

# 5. 1個の内部状態

神経区画には、1つの漏れ積分状態があります。

概念的には、

\[
h_t = h_{t-1} + \alpha\left[\tanh(g\,x_t)-h_{t-1}\right]
\]

です。

P1には他の神経細胞も再帰シナプスもありません。したがってこれはニューラルネットワークというより、**物質的な1状態情報処理区画**です。

この小ささは意図的です。1区画でも費用を回収できないなら、8細胞や48細胞へ増やす理由がないためです。

# 6. 局所的な次流入予測

区画は次時刻の、

- 局所濃度
- x勾配
- y勾配
- 膜流入

を予測します。

予測更新は局所誤差だけを使います。

\[
\Delta W = \eta\,(y_{t+1}-\hat y_{t+1})\,\phi_t
\]

P1では、重みは有限区画タンパク質上の可逆修飾状態の粗視化です。予測計算の費用はダミーにも同じ固定維持費として課し、情報処理だけを無料優遇しないようにしています。

制御されたmoving-patch時系列で、予測RMSは、

```text
初期60観測平均: 0.447203
終盤60観測平均: 0.143617
```

まで低下しました。

ただし比較実験では、予測を止めた条件の平均自己生産余裕が、完全P1よりわずかに高くなりました。

```text
完全P1           0.607724
予測なし         0.612921
```

したがって、現時点で言えるのは、

> 予測器は対象時系列を学習するが、その予測を方向選択へ混ぜる現在方式が身体利益を生むとはまだ示せない

ということです。

この負の結果を隠さず、P2では予測の使い方をアブレーション対象に残します。

# 7. 行動は身体への要求

神経区画は単位方向を選び、一定強度の、

```text
motor
transporter_polarity
```

要求をP0へ送ります。

P0身体は、

- ATP
- 有限シグナル
- 実エフェクタータンパク質
- 膜状態

に応じて実行可能量だけを適用します。

等しい初期身体状態から、神経とダミーが同じ大きさの要求を一回出した検証では、総有料コストは、

```text
神経 : 0.00040139944
ダミー: 0.00040147943
```

でした。

方向が異なるため輸送体の局所配置による微小差はありますが、命令ノルムと費用規模は一致しています。

# 8. 等費用ダミー対照

P1の比較対象は「脳なし」だけではありません。

`dummy`区画は、神経区画と同じ、

- 遺伝カセット
- 物質目標
- 発生速度
- 維持ATP
- 有限シグナル
- 摩耗率
- 更新周期
- 運動要求の大きさ
- 輸送体偏在要求の大きさ

を持ちます。

違いは方向決定だけです。

```text
神経区画: 実リガンドの膜勾配
ダミー  : 身体外界と無関係な内部振動子
```

エフェクターを無効化した比較では、80 step後も両条件の身体化学、世界、組織材料、予算店舗、総支出が一致しました。

行動開始後は、取得資源が異なるため実支出も分岐します。これは不公平なコスト差ではなく、情報利用によって将来の支払い能力自体が変わった結果として記録します。

# 10. 24試行の工学比較

3 seed × 8条件、各40シミュレーション秒、合計24試行です。

## 10.1 moving-patch環境

資源パッチ中心は16秒ごとに、

```text
右 → 左 → 上 → 下
```

へ切り替わります。粒子は新しい中心へ物理的に移動し、細胞には切替時刻も中心座標も通知しません。

| 条件 | 平均自己生産余裕 | 累積流入 | 神経ATP | 予測誤差 |
|---|---:|---:|---:|---:|
| **1物質神経** | **0.607724** | **1.475465** | 0.139591 | 0.258172 |
| 等費用ダミー | 0.471533 | 0.130273 | 0.060669 | 0.643375 |
| 予測なし | **0.612921** | 1.444926 | 0.144965 | 0.234213 |
| エフェクターなし | 0.562128 | 0.156053 | 0 | 0.258680 |
| 神経カセットのみ | 0.580181 | 0.164298 | 0 | 0 |
| カセットも組織もなし | 0.599605 | 0.172979 | 0 | 0 |

神経区画とダミーのpaired差は次でした。

```text
自己生産余裕:
seed 101 +0.125964
seed 202 +0.153089
seed 303 +0.129521

物質流入:
seed 101 +1.404287
seed 202 +1.331264
seed 303 +1.300027
```

**3/3 seedで神経区画が等費用ダミーを上回りました。**

自己生産余裕は、神経のATP・材料・摩耗費を支払った後の身体状態から計算されています。したがって今回の小環境では、情報を使った方向選択が区画費を上回ったと判定します。

## 10.2 stable-patch環境

| 条件 | 平均自己生産余裕 | 累積流入 | 平均パッチ距離 |
|---|---:|---:|---:|
| **1物質神経** | **0.633884** | **2.087726** | **0.096530** |
| 等費用ダミー | 0.446906 | 0.057879 | 0.252737 |

固定資源でも神経区画が3/3 seedで優位でした。

## 10.3 解釈上の注意

ダミーの実ATP支出が神経より少ないのは、初期の要求設定が安いからではありません。方向選択が悪く資源を取得できず、後半に同じ要求を十分に支払えなくなったためです。

また、パッチまでの平均距離だけではmoving条件の結果を説明できません。ダミーは一部時間帯で幾何学的に近くても、輸送体偏在と接触軌道が資源流入へ結び付きませんでした。

# 11. P1の合格判定

P1の目的は、1個の物質神経区画がすべての環境で最良になることではありません。

合格条件は、

1. P0身体契約を破らない
2. ゲノムと実材料から発生する
3. 等物質・等維持ダミーを用意する
4. 外部化学情報を使ったことに、少なくとも一つの非定常環境で純身体利益がある
5. 死・分裂・保存で台帳と決定論を守る

ことです。

今回、これらを満たしたため、**SOMA-CELL 0.6-P1を合格・凍結候補**とします。

ただし局所予測の行動利益は未達です。P1の成功は「情報に基づく1状態制御」の成功であって、「予測脳の有用性」まで証明したものではありません。

# 14. 次の段階 — SOMA-CELL 0.6-P2

P2では8細胞の小型組織へ進みます。

予定する順序:

```text
ゲノム由来の8細胞型
↓
有限シグナル分子を使う疎な再帰結線
↓
細胞ごとのATP・タンパク質費
↓
局所予測
↓
適格度トレース
↓
自己生産変化を第三因子とする三因子可塑性
↓
等物質固定組織・可塑性なし・再帰なしとの比較
```

P1の負の結果を踏まえ、予測器は「搭載したから価値がある」と仮定しません。P2でも予測なし条件を必須アブレーションとして残します。

## 配布リビジョンR1

初回アーカイブの`SHA256SUMS.txt`に自己参照行が含まれ、`sha256sum -c`でその1行だけ失敗する包装上の問題がありました。また、検証スクリプトのP0ソース確認がリポジトリ配置だけを想定していました。R1では、チェックサム自身を対象外にし、フラットなPythonista配布フォルダでも18/18検証を実行できるよう修正しています。シミュレーション本体と測定結果は変更していません。
