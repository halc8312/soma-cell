# SOMA-CELL 0.6.2 物質神経代謝監査契約

## 目的

SOMA-CELL 0.6.1の物質身体・8区画神経・因果監査を壊さず、予測、再帰、可塑性、能動診断、神経区画数のATP・材料費を明示的に測り、費用を回収できない機構を休眠または除去する。

## 凍結公理

1. 0.6.1 UI1のコンパクトHUDと、子クラスを保つ安全なダブルタップリセットを継承する。
2. 神経モジュールの活動はATP、タンパク質、有限信号物質を消費する。
3. `metabolic_meter_enabled=False`は明示的な外部検証ハーネス以外では失敗閉鎖する。
4. 神経区画を減らす場合、未使用予算と組織物質をP0身体ポートへ保存的に返す。
5. 非活動区画の重み・活動・成熟状態を、活動中の計算や学習へ混入させない。
6. 神経出力は身体への要求であり、位置、ATP、膜、DNAを直接変更しない。
7. 分裂時に学習済み状態を無料コピーしない。
8. 負の結果を隠さず、機構数の多さを成功条件にしない。

## 監査対象

- `prediction`: 局所次入力予測
- `recurrence`: 有限信号物質を使う再帰結線
- `plasticity`: 適格度・三因子更新
- `diagnosis`: 外部分子の能動的意味診断
- `tissue size`: 8 / 4 / 2 / 1 / 0区画

## 物質計測

各モジュールについて、少なくとも次を累積する。

- ATP支出
- 損傷タンパク質・凝集体として残る材料摩耗
- 実行回数
- 休眠区画数
- 身体へ返却したATP・材料

## プロファイル

- `full8`: 8区画、予測、再帰、可塑性、診断
- `no_prediction`
- `no_recurrence`
- `no_diagnosis`
- `no_plasticity`
- `size4` / `size2` / `size1`
- `efficient4`: 4区画、予測、可塑性、再帰なし、能動意味診断なし
- `efficient2`: 2区画、予測、可塑性、再帰なし、能動意味診断なし
- `no_tissue`: 追加P2神経組織なし

## 事前登録結果による決定

### 予測

`no_prediction`が`full8`を上回ったのは1/4系列であり、棄却基準を満たさなかった。研究用最小神経プロファイルでは保持する。

### 再帰

`full8`が`no_recurrence`を上回ったのは2/4系列で、保持基準3/4を満たさなかった。既定では休眠する。

### 区画数

確認試験では`efficient2`が試した神経プロファイル中で最高の費用込み身体余裕を示したが、`no_tissue`を下回った。

したがって、試験条件における代謝監査の選択結果は次である。

```text
AUDIT_SELECTED_PROFILE = no_tissue
MINIMAL_NEURAL_RESEARCH_PROFILE = efficient2
```

Pythonistaの可視化では神経状態を観察できるよう`efficient2`を研究実行プロファイルとして用いるが、これを純利益が証明された最適器官とは呼ばない。

## 合格と限定

### 工学合格

- 0.6.2専用検証24/24 PASS
- 継承回帰127/127 PASS（P0/P1/P2/0.6/0.6.1）
- 保存復元、共通外乱、物質台帳、平坦Pythonista配置
- UI1表示・リセット修正の保持

### 科学的負の結果

- スクリーニング、確認の両方で`no_tissue`の費用込み身体余裕が全追加神経プロファイルを上回った。
- 現在の追加神経層は、短いcue-reversal課題で自分の発生・維持費を回収していない。
- `full8`の故障保全リースは6/6で正の差を保ったが、神経層全体の純利益を証明しない。

## 次の段階

SOMA-CELL 0.6.3では、常時脳を維持せず、環境変動・情報価値・身体予算に応じて神経組織を発生、休眠、再吸収する需要連動型ニューロジェネシスを検証する。
