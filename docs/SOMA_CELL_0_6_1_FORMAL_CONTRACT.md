# SOMA-CELL 0.6.1 因果証拠充足・機構保全契約

更新日: 2026-08-03  
凍結実装: `SOMA-CELL 0.6.1` / implementation schema `0.6.1-D1.4`  
正式リリース契約: `0.6.1-R2.0`

## 目的

SOMA-CELL 0.6.0の物質的因果監査を壊さず、次を追加する。

1. 「変化なし」と「証拠不足」を分離する証拠台帳。
2. ATP・信号物質・損傷費を払う、短時間かつ安全境界付きの診断曝露。
3. 有料の反復校正パルスによる、神経命令から実推進力への変換効率監視。
4. 確認された運動器故障後にだけ、運動へ正に寄与する神経区画を一時休眠させる資源保全リース。
5. 神経ATP／信号エスクローの上限化と、未使用物質の身体への保存的返却。

## 継承する凍結公理

- 境界は局所膜材料から生じる。
- 神経活動・診断・監査・記憶はATPと実物質を消費する。
- 神経出力は身体ポートへの要求であり、位置・ATP・膜・DNAを直接変更しない。
- 遺伝可能な神経機能は実DNA、翻訳、発生を必要とする。
- 学習状態・証拠・リースを娘へ無料コピーしない。
- 死んだ神経物質は身体／死体化学へ戻す。
- 外部reward、fitness、正解方向を最上位目的へ渡さない。

## 0.6.1で追加する物質制約

- 再利用可能な神経ATPバッファは原則1区画あたり約0.002以下。
- コントローラーATPバッファは原則約0.004以下。
- タンパク質・膜組立に必要なATPだけは、そのステップの実組立量に比例して追加できる。
- 保全リースは物質を削除せず、対象区画の一時的なATP・信号・活動・身体出力上限だけを縮小する。
- リース終了後に学習済み重みを正確に復元する。活動低下と支出低下だけが物理結果として残る。

## 対象選択

絶対運動強度だけでは、現在の運動へ逆向きに働く拮抗区画を誤って休眠させ得る。正式0.6.1では、各区画の局所運動ベクトルを現在の組織自身の運動方向へ射影し、正の仕事をしている区画を優先する。外部の資源座標や正解方向は使用しない。

## 故障確認

- 通常の命令→推進力関係から基準利得を形成する。
- 機構異常が疑われた場合だけ、有料の短い校正パルスを実行する。
- 複数回の校正で利得低下が再現されるまで故障確定しない。
- 故障未確認、身体危機、物質支払い不能ではリースを発行しない。
- 機構回復時または期限切れでリースを撤回する。

## 合格判定

### 工学合格

- 0.6.1専用43/43 PASS。
- P0/P1/P2/正式0.6回帰84/84 PASS。
- 合計127/127 PASS。

### 科学的限定

- 主な正の証拠は制御された機構故障と物質保存型浴に由来する。
- 自然空間6系列でも身体余裕差は正だが、物質取得改善は示されていない。
- 外部分子の意味を能動診断する経路は費用回収が未確立。
- 予測器と再帰結線の正味身体価値は未確立。
- 長期多世代での神経診断遺伝子の定着は未証明。

したがって0.6.1は、`engineering PASS / scientific PASS_WITH_LIMITS`として凍結する。
