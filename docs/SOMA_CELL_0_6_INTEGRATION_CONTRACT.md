# SOMA-CELL 0.6 既存SOMA再統合契約

この文書は、SOMA-CELL 0.6で既存SOMA神経系を物質的自己生産細胞へ戻す際の、破ってはいけない境界とインターフェースを定める。

## 1. 統合の目的

「化学身体の上に神経ネットワークを載せる」だけではなく、神経組織自身も外界由来の物質から作られ、ATPを消費し、損傷・修復・発生・遺伝・死亡後の分解と水平移動の対象となる一つの自己生産系へする。

0.6の最小合格条件は、神経系なしの0.5細胞より少なくとも一つの非定常環境で適応が改善し、その利益が神経組織の物質・エネルギー費を上回ること。同時に、神経系を止めても身体化学の保存則が破れず、基礎0.5細胞が存続できること。

## 2. 凍結する物質的公理

1. 個体境界は膜材料の局所分布から生じる。
2. 内部／外部の非対称輸送を維持する。
3. 遺伝可能なゲノムコピーはモノマー、ATP、複製酵素を必要とする。
4. 死はhealth値ではなく、境界と反応循環の回復不能な崩壊で定義する。
5. 神経組織、受容体、運動器、記憶のすべてに物質量と維持費を持たせる。
6. 分裂・死・漏出・合成・死体分解・環境DNAの物質台帳を継続する。
7. 外部報酬や教師ラベルを最上位目的として追加しない。
8. 死亡した神経組織は匿名削除せず、死体のprotein/structural/toxic/genomeプールへ移す。
9. 水平遺伝は環境中の実在DNA断片、competence、ATP、組換え／分解を介する。
10. 可動配列、感染、restriction、nucleaseの宿主費用と競合を消さない。

## 3. 初期統合元

### 必須で移植する

- SOMA-1: 疎な再帰細胞、局所予測、三因子可塑性、細胞別代謝、成熟・再可塑化
- SOMA-2/2.1: 細胞群の実停止監査、証拠品質、期限付き因果権
- SOMA-4/4.1/4.2: 反証コンパイラ、同一乱数ツイン評価、因果校正、変化感受性ゲート
- SOMA-CELL 0.4: ゲノム由来受容体、膜局所化、ATP支払い収縮、輸送体極性、物質流トレース、自己生産余裕に基づく局所可塑性
- SOMA-CELL 0.5: 空間死体、環境DNA、物質HGT、restriction/nuclease、死体利用、可動配列と宿主費用

### 最初の0.6では保留する

- SOMA-5Rの概念・多段内的世界
- SOMA-6Rの文化通信
- SOMA-7Rの多個体生態系

これらは、単細胞0.6が物質収支の下で安定し純利益を示した後に0.6.xとして戻す。

## 4. 化学身体と神経組織の境界API

概念上の最小インターフェースは次の通り。

```python
class ChemicalBody:
    def raw_sensor_fluxes(self) -> dict:
        """膜区画の実分子量・流入、張力、温度、ATP、損傷、廃棄物等。"""

    def allocate_budget(self, tissue_id, requests, dt) -> dict:
        """ATP・アミノ酸相当物質・膜材・信号分子を実在量以内で割り当てる。"""

    def apply_effector_fluxes(self, tissue_id, fluxes, dt) -> None:
        """ポンプ、収縮、膜変形、分泌等を物理上限内で実行する。"""

    def return_dead_tissue(self, tissue_id, products) -> None:
        """壊れた神経物質を死体・廃棄・再利用プールへ保存的に戻す。"""

class NeuralTissue:
    def step(self, sensors, granted_budget, dt) -> dict:
        """局所活動と学習を進め、物理エフェクタ要求と物質廃棄を返す。"""

class DevelopmentProgram:
    def grow_tissue(self, genome, proteins, chemical_context, dt) -> None:
        """ゲノムと局所化学から受容体・神経細胞・結線を発生する。"""
```

APIは実装時に変えてよいが、以下は禁止する。

- 神経出力が直接位置、膜量、ATP、DNA配列を書き換える
- 予算を超えてATPや材料を使う
- センサーが外界の正解ラベルを受け取る
- 脳の学習状態をPythonオブジェクトとして無料遺伝する
- 神経遺伝子をHGTフラグとして無料コピーする
- 神経細胞の死亡・刈り込みで物質を消去する

## 5. 旧SOMA身体通貨の物質変換

SOMA-1の4通貨は抽象値のまま持ち込まない。

| 旧通貨 | 0.6での物質的根拠 |
|---|---|
| energy | ATP、還元力、利用可能燃料、複製モノマー |
| thermal | 温度依存反応速度、膜流動性、変性タンパク質 |
| integrity | 膜セグメント材料、漏出率、触媒・神経物質保持率 |
| fatigue | ATP負債、損傷タンパク質、凝集体、反応性副産物、回復遅延 |

神経細胞が得る資源は、これらの実在物質・反応能力の割当として実装する。

## 6. 神経細胞の物質化

各神経細胞は最低限、次を持つ。

- 膜／局所区画材料
- 受容体・チャネル相当タンパク質量
- ATP消費
- 有限な神経伝達／信号分子
- 損傷、凝集、分解、再合成
- 発生元遺伝子と調節領域
- 死亡・刈り込み後に回収可能な物質組成

細胞数48は比較対照に使ってよいが、0.6本体は8〜12細胞から開始し、最終的には発生プログラムと資源配分の結果として変化させる。

## 7. 学習と因果監査の物理制約

- 発火、予測、可塑性、構造変更にはATPと材料を課す
- 神経停止監査は該当細胞への物質／シグナル流を可逆遮断して行う
- 監査中の身体文脈、ATP費、損傷、副作用を記録する
- 因果寄与が低い組織は物質回収・分解・別組織への再利用候補にする
- 反証後の再可塑化は0.3の損傷証拠、0.4の自己生産変化、0.5の感染・HGT・死体環境変化でゲートする
- 神経実験の利益は実験中費用を差し引いた純身体利益で測る

## 8. 感覚運動公理

1. センサー入力は外界ラベルではなく、膜区画で実測した分子量、流入、張力、温度、内部化学である。
2. 神経出力は位置を直接変更せず、膜収縮、輸送体再配置、ポンプ、将来の鞭毛等へ物理要求を出す。
3. 感知、運動、情報更新にはATPと物質費を課す。
4. 0.4の固定反射表は比較対照であり、0.6の価値関数にしない。
5. 自己生産余裕は最終報酬ではなく局所調節信号。膜閉鎖、ATP、反応循環、損傷、ゲノム機能、漏出の実測値から再計算する。
6. 学習状態の継承はタンパク質修飾、局所分子濃度、発生調節等の明示的物質へ写像する。

## 9. 死体化学・環境DNA・HGT公理

1. 神経組織を含む死亡個体は、位置と由来を持つ物質死体になる。
2. 神経発生遺伝子・受容体遺伝子・可塑性規則が水平移動する場合、実在DNA断片として移動する。
3. 移入遺伝子は通常翻訳と発生を経るまで機能しない。
4. restriction、nuclease、competence、recombinaseの費用と失敗を維持する。
5. 可動配列は宿主利益のためだけに設計せず、ゲノム肥大・ATP費・感染リスクを持つ。
6. 神経組織由来の死体タンパク質を摂取しても、抽象記憶や重みをそのまま取得しない。
7. 死体から得られる一時的物質状態と、ゲノムに組み込まれる長期遺伝を区別する。

## 10. 遺伝と発生

神経系の継承対象は学習済み重みの直接コピーではない。継承可能なのは原則として次。

- 神経細胞型を生成する遺伝子
- 受容体、エフェクタ、可塑性規則をコードする遺伝子
- 発生位置や結線傾向を決める調節配列
- 分裂時に物質として分配される一時的タンパク質／シグナル組成
- 水平移動した実在DNA断片が通常複製・発現を経て定着したもの

学習済み結線を継承する場合は、膜上標識、局所分子濃度、エピジェネティック修飾等の明示的物質として保存する。

## 11. 最低限のアブレーション

1. 神経組織なし
2. 神経活動あり・可塑性なし
3. 局所予測なし
4. 因果監査なし
5. 反証フィードバックなし
6. 神経コストなし（不正な上限比較）
7. 抽象旧通貨を復活させた条件
8. 発生ゲノムなし・固定48細胞
9. 物質的記憶なし・無料重み継承
10. 同一初期状態・共通乱数ツイン
11. 神経死体を匿名削除
12. 神経遺伝子HGTなし／無料HGT
13. restrictionなし
14. 可動配列なし

## 12. 0.6合格判定

- 物質台帳残差が許容範囲内
- 神経組織が自分の維持費を化学的に支払う
- 神経系あり条件が少なくとも一つの非定常環境で純身体利益を示す
- 安定環境で神経コストが恒常的損失を生まない
- 介入予測と実測効果が偶然以上に校正される
- 学習済み状態の無料親子コピーに依存しない
- 神経系を除去しても基礎プロトセルは0.5相当として存続可能
- 神経組織の形成・刈り込み・死亡を含めても物質保存が成立
- HGTした神経遺伝子が通常翻訳・発生なしに即時機能しない
- Scene表示だけでなくヘッドレス反復試験で再現する

## 13. 統合順序

```text
0.5化学身体を固定
  ↓
0.4受容体・エフェクタを物理I/Oとして維持
  ↓
ゲノム由来8〜12細胞の小型神経組織
  ↓
局所予測と三因子可塑性
  ↓
神経コストを含む共通乱数ツイン評価
  ↓
実停止監査、因果校正、変化感受性ゲート
  ↓
神経組織の死体化・分解・神経遺伝子HGT検査
  ↓
必要性が示された場合だけ細胞数と実験言語を拡張
```

48細胞全機構を一度に戻さない。
