# SOMA-CELL 0.6-P0 化学身体API契約

契約版: `0.6-P0.1`  
実装版: `SOMA-CELL 0.6-P0.0`

この文書は、P1以降の物質神経組織が0.5化学身体へ接続するときの、失敗閉鎖インターフェースを定める。P0自体には情報処理神経、学習、因果監査、外部報酬はない。

## 1. 不変条件

1. 神経未接続時の身体・世界・乱数軌道は凍結0.5と完全一致する。
2. センサー読出しは状態も乱数も変更しない。
3. ATP以外の予算は世界の総物質台帳に含まれる。
4. 予算は身体の実在残量・身体予備・時間当たり上限を越えない。
5. エフェクタ要求は既存0.5の膜収縮、輸送体再配置、修復極性、休眠機構だけを通る。
6. 位置、速度、膜量、ATP、DNA、ゲノムを直接書き換えない。
7. 組織物質を削除しない。死亡・切離し・宿主死・分裂前に保存的に分解プールへ返す。
8. 学習済み状態や組織を娘へ無料コピーしない。

## 2. `raw_sensor_fluxes(tissue_id=None)`

返値は再帰的に不変化された読み取り専用マッピングである。配列はコピーされ、書込み禁止になる。

主要区画:

- `membrane`: 36区画の材料、閉鎖度、酸化、損傷痕跡、輸送体、張力、半径、漏出
- `external`: 実粒子プロファイル、リガンドプロファイル、局所ストレス、死体・eDNA・毒性信号
- `flux`: 直近の膜通過量、表面フラックス、排出、DNA取込み、死体摂食
- `internal`: 13物質プール、ATP、燃料、鉱物、廃棄物、反応性物質、損傷、凝集体、ゲノム損傷、反応循環など
- `velocity`: 現在の物理速度

次は渡さない: `reward`, `fitness`, `correct_action`, `food_direction`, `autopoietic_margin`, 絶対位置、世界時刻、細胞年齢。

## 3. `allocate_budget(tissue_id, requests, dt)`

予算区分:

- `atp`: 活動・組立・エフェクタ用化学エネルギー
- `protein`: 燃料68%＋鉱物32%から移すタンパク質前駆体
- `membrane`: 膜前駆体
- `signal`: 燃料56%＋鉱物44%から移す有限信号前駆体

要求は非負有限値でなければならない。未知の区分、非正の`dt`、NaN、負値は状態変更前に拒絶する。

供給量は次の最小値である。

```text
要求量
時間当たり供給上限 × dt
身体に残す予備を除いた実在量
```

複数組織は同じ身体残量を共有する。後の要求が先の割当を無視することはできない。

## 4. `return_unused_budget(tissue_id, amounts=None)`

未使用のエスクローを、元のATP・燃料・鉱物・膜前駆体へ逆変換する。組立済み組織は「未使用」として返せない。

## 5. `commit_material(...)`

前駆物質を組織物質へ組み立てる。ATP費:

```text
protein  0.44 ATP / material
membrane 0.18 ATP / material
signal   0.24 ATP / material
```

保有材料またはATPが不足する場合は、全成分を同じ比率で縮小する。P0では組織機能や遺伝的細胞型を付与しない。P1はゲノム由来組立機構を追加しなければならない。

## 6. `apply_effector_fluxes(tissue_id, fluxes, dt)`

許可キー:

- `motor`: 方向ベクトル。既存膜運動系へ有限力を加える。
- `transporter_polarity`: 輸送体総量を保存した方向再配置。
- `repair_polarity`: 既存修復極性を方向づける。
- `quiescence`: 既存休眠状態を有限に強める。

各要求は組織が保有するATP・有限信号と、身体側エフェクタタンパク質に制約される。API呼出し中に位置は変化せず、その後の通常物理更新によってのみ変位する。

禁止キーまたは未知キーは、厳格モードで例外となり、拒絶回数へ記録される。

## 7. `return_dead_tissue(tissue_id, reason, remove=True)`

返却先:

- 機能／損傷タンパク質 → 神経由来損傷タンパク質
- 凝集体 → 凝集体プール
- 組織膜・未使用膜 → 膜前駆体
- 信号物質 → 廃棄物
- 毒性物質 → 反応性物質
- 組織内ATP → 散逸エネルギー

宿主死亡時はこの返却後に0.5の空間死体へ変換される。分裂前は返却後に通常物質として娘へ分配されるが、神経組織・学習状態としては継承されない。

## 8. P1への義務

P1の1神経細胞は、このAPIの外から身体状態を変更してはならない。また、最低限次を物質化する。

- 組織膜
- チャネル／受容体タンパク質
- 有限信号物質
- ATP消費
- 損傷、分解、再合成
- ゲノム由来の発生

比較対照は、同量のATP・タンパク質・膜・信号を保持する情報処理なしダミー組織とする。
